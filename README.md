# skaut/wordpress-version-checker

A GitHub app to automatically create issues when a plugin "tested up to" version doesn't match the latest WordPress version.

Hardened by [Chainguard](https://www.chainguard.dev) from the upstream action at [https://github.com/skaut/wordpress-version-checker](https://github.com/skaut/wordpress-version-checker).
